# AlzheimerCare

Plataforma de gerenciamento de cuidados para pacientes com Alzheimer, projetada para cuidadores familiares e profissionais.

## Objetivo

Centralizar e simplificar o dia a dia de quem cuida de pacientes com Alzheimer, oferecendo ferramentas integradas para medicação, rotina, comunicação, monitoramento de saúde e suporte emocional.

## Funcionalidades

- **Medicação** — Controle de horários, doses e histórico de medicamentos com alertas e calendário integrado
- **Rotina & Calendário** — Organização de atividades diárias, compromissos e eventos com visualização em calendário
- **Comunicação** — Chat em tempo real entre cuidadores, com gerenciamento de contatos e chamadas rápidas
- **Estado do Paciente** — Monitoramento de humor, dor, sono e sintomas com gráficos de tendência (média móvel, trendlines)
- **Suporte Emocional** — Recursos, notas e comunidade para apoio aos cuidadores
- **Dashboard** — Visão geral com contadores dinâmicos de tarefas completas, pendências e mensagens não lidas

## Stack Tecnológica

- **Frontend**: React 18 + TypeScript + Vite 5
- **UI**: Tailwind CSS v3 + shadcn/ui
- **Backend**: Lovable Cloud (autenticação, banco de dados, realtime, storage)
- **Gráficos**: Recharts

## Como usar

1. Acesse a aplicação e crie uma conta
2. Faça login e explore o dashboard central
3. Adicione medicações, eventos de rotina e contatos
4. Monitore o estado do paciente diariamente
5. Use o chat para comunicação entre cuidadores

## Desenvolvimento local

```bash
npm install
npm run dev
```
